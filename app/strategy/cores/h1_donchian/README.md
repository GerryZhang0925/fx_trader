# h1_donchian（Explore）

ライブ H4 ドンチャン 3 本とは別コア。H1 の 20 本チャネル抜け＋ATR トレイル。YAML 既定オフ。ピンしない。年率 36–38% や相関 0.3–0.5 は目標ではない。スタンドアロンで測る。add-on ゲートはピンしてから。

import: `from strategy.cores.h1_donchian import H1DonchianStrategy`

## 仕様（未ピン）

- 足: H1（M15 CSV なし。ライブは H4 なので、同じ H4 長さ 20 にはしない）
- ペア: EURUSD / GBPUSD / USDJPY / USDCAD
- エントリー: 確定終値が直前 20 本の高値／安値を越える。終値が EMA200 の順方向
- ADX・ATR 中央値フィルタなし（ライブ JSON のピンをコピーしない）
- 損切り: スイング ± ATR×0.5（下限 0.35 ATR）
- トレイル: ATR×2.5。反対チャネル抜けで手仕舞い。部分利確なし
- セッション制約なし。次バー始値。1 pip + 0.2。研究リスク 2%

H1 ドンチャンをライブ冊の衛星として足した履歴は DROP のまま。これはそのオーバーレイの復活ではなく、別コアの Explore。

```bash
export PYTHONPATH=app
python -m strategy.cores.h1_donchian.backtest.eval
```
