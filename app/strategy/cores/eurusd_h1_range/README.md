# EURUSD H1 range fade（研究）

H4 ドンチャン 3 本は凍結。ライブ既定オフ。グリッドしない。EURUSD 1% 衛星としての加算は **DROP**（lockbox DD 15.4%）。4 ペア・2% はスタンドアロン Explore。ピンしない。PF 1.55 は目標ではない。

import: `from strategy.cores.eurusd_h1_range import EurusdH1RangeStrategy`

## 仕様（4 ペア化でも同じ）

- 足: H1。M15 は CSV なし。
- レジーム: 確定済み H4 の ADX(14) **< 20**（表から外さない。1.55 の計測に入っている）
- セッション: ロンドン〜NY 重なり（DST。固定 UTC 13–17 ではない）
- エントリー: 確定バーで RSI(14) < 30 ロング / > 70 ショート。終値が EMA50 より不利側
- 損切り: スイング ± ATR×0.5（下限 0.35 ATR）
- 利食い: シグナルバーの EMA50。または 20 H1。トレイルなし
- コスト: 1 pip + 0.2
- エンジン停止: 口座設定どおり（1 日 2 本、連敗 3、日次 −2R）。年 80–120 本にはならない

```bash
$env:PYTHONPATH="app"
python -m strategy.cores.eurusd_h1_range.backtest.eval
python -m strategy.cores.eurusd_h1_range.backtest.eval_four
```

## EURUSD 1%（衛星、DROP）

学習 <2021 / lockbox 2021–2025。加算は独立パスの日次 PnL 合算。

| 分割 | 本数 | PF | 平均 R | 年率 | 最大 DD |
|---|---|---|---|---|---|
| 学習 <2021 | 202 | 1.31 | 0.28 | 10.4% | 28.2% |
| lockbox 2021–2025 | 214 | 1.55 | 0.45 | 24.4% | 32.5% |

H4 3 本（5%）年率 35.4%、DD 11.6%。足すと年率 44.1%、DD **15.4%**、日次相関 **−0.05**。DD がキャップ 15% と H4 単体を超えるので衛星 **DROP**。パラメータは触らない。

## 4 ペア・2%（スタンドアロン、未ピン）

同じルール。加算していない。2021–2025 はドンチャン選定に使った窓なので弱証拠。2026 は本数が 16–41 と少ない。

| ペア | 分割 | 本数 | PF | 年率 | DD |
|---|---|---|---|---|---|
| EURUSD | <2021 | 202 | 1.279 | 22.3% | 49.3% |
| EURUSD | 2021–2025 | 214 | 1.512 | 60.9% | 55.3% |
| EURUSD | 2026-01.. | 23 | 2.296 | 55.3% | 17.2% |
| GBPUSD | <2021 | 223 | 2.015 | 58.5% | 37.2% |
| GBPUSD | 2021–2025 | 192 | 1.705 | 69.9% | 34.1% |
| GBPUSD | 2026-01.. | 25 | 1.143 | 6.5% | 22.4% |
| USDJPY | <2021 | 216 | 1.200 | 35.7% | 58.5% |
| USDJPY | 2021–2025 | 202 | 1.311 | 21.6% | 47.9% |
| USDJPY | 2026-01.. | 41 | 1.324 | 24.6% | 23.3% |
| USDCAD | <2021 | 212 | 2.002 | 163.8% | 31.5% |
| USDCAD | 2021–2025 | 205 | 1.819 | 148.8% | 32.2% |
| USDCAD | 2026-01.. | 16 | 2.214 | 31.9% | 15.7% |

EURUSD 2021–2025 は本数 214・PF 1.51 で 1% 時の 1.55 と揃う。2% にすると年率と DD が膨らむ（DD 32.5%→55%）。想定の年 80–120 本・DD 20–30%・PF 1.55 維持にはならない。USDJPY lockbox PF 1.31 は EURUSD 1.51 より低いが、学習 1.20・2026 1.32 と符号は揃う（日足 BB の学習 0.91 / 2026 0.63 とは違う）。2026 は全ペア PF>1 だが本数が 16–41 と少なく、確認にも棄却にも足りない。USDCAD の年率 149% は 2% 複利であり目標にしない。決済は損切りが過半（EURUSD lockbox 214 中 stop 162、take_profit 28）。ピンしない。

衛星としての加算 DROP は維持する。スタンドアロンを「2021–2025 だけ効いた」として Explore DROP にはしない（学習・lockbox・2026 がすべて PF>1）。ライブは H4 ドンチャン 3 本のみ。衛星コアは YAML `false` のまま監視対象にしない（新規エントリーを足さない）。

これは手法の点検であり、売買助言ではない。
