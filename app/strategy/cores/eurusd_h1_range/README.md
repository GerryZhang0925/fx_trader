# EURUSD H1 range fade（研究衛星）

H4 ドンチャン 3 本は凍結。このコアは EURUSD だけ、リスク 1%、ライブ既定オフ。グリッドしない。成績はチェックリストであり保証ではない。

import: `from strategy.cores.eurusd_h1_range import EurusdH1RangeStrategy`

## 凍結仕様

- 足: H1（既存 Dukascopy CSV）。M15 は lockbox が壊れなかったときだけ
- レジーム: 確定済み H4 の ADX(14) **< 20**
- セッション: ロンドン現金 08–16 と NY 現金 08–17 の重なり（DST あり。固定 UTC 13–17 ではない）
- エントリー: 確定バーで RSI(14) < 30 ロング / > 70 ショート。終値が EMA50 より不利側にあるときだけ
- 損切り: スイング ± ATR×0.5（下限 0.35 ATR）
- 利食い: シグナルバーの EMA50（トレイルなし、部分利確なし）。または **20 H1 バー** で次バー始値クローズ
- コスト: まず 1 pip + 0.2。通ったら 1 + 0.4
- ダイバージェンスは使わない（後段の別仮説）

## 検証

学習 <2021 で計測。2021–2025 は lockbox **1 回**。PF≥1.2 は必須にしない。PF<1 なら棄てる。生き残ったら H4 3 本に 1% で足し、年率・DD・相関を見る。悪化または DD>15% なら棄てる。

```bash
$env:PYTHONPATH="app"
python -m strategy.cores.eurusd_h1_range.backtest.eval
```

## 1 回目の計測（仕様は変えていない）

リスク 1%、コスト 1 pip + 0.2。学習 <2021 / lockbox 2021–2025。加算は独立パスの日次 PnL 合算。

| 分割 | 本数 | PF | 平均 R | 年率 | 最大 DD |
|---|---|---|---|---|---|
| 学習 <2021 | 202 | 1.31 | 0.28 | 10.4% | 28.2% |
| lockbox 2021–2025 | 214 | 1.55 | 0.45 | 24.4% | 32.5% |

lockbox の H4 3 本（5%）年率 35.4%、DD 11.6%。足すと年率 44.1%、DD **15.4%**、日次相関 **−0.05**。DD がキャップ 15% と H4 単体を超えるので **DROP**。パラメータは触らない。M15 には落とさない。

これは手法の点検であり、売買助言ではない。
